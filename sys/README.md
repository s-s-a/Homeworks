## ⚙️ Как начать

Чтобы приступить к выполнению, следуйте этим шагам.

### Шаг 1: Клонируйте репозиторий

Сначала вам нужно скопировать все файлы этого проекта к себе на компьютер. Откройте терминал (или Git Bash на Windows) и выполните команду:

```bash
git clone https://github.com/Zaplavs/sys_homework.git
cd sys_homework
```

### Шаг 2: Создайте и активируйте виртуальное окружение

Это хорошая практика, которая позволяет изолировать зависимости проекта.

```bash
# Создаем окружение в папке 'venv'
python -m venv venv

# Активируем его:
# Для Windows
venv\Scripts\activate

# Для macOS / Linux
source venv/bin/activate
```
После активации вы увидите `(venv)` в начале строки вашего терминала.

### Шаг 3: Установите `pytest`

Для проверки ваших решений мы используем фреймворк `pytest`. Установите его:

```bash
pip install pytest
```

### Шаг 4: Установка зависимостей

Для работы с проектом вам понадобится Python 3.6 или выше и pip. Установите зависимости:

```bash
pip install -r requirements.txt
```

### Шаг 5: Выполняйте задания!

Каждое задание находится в папке `tasks`. В отличие от других заданий, здесь вы будете создавать исполняемые скрипты, которые принимают аргументы командной строки и работают с системными потоками.

**Ваша цель — создать скрипты, которые соответствуют требованиям каждого задания.**

## ✅ Как проверить свое решение

Для каждого задания есть свой тестовый файл. Чтобы проверить конкретное задание, выполните в терминале команду:

```bash
# Для проверки Задания 1
python -m pytest tests/test_task_1.py

# Для проверки Задания 2
python -m pytest tests/test_task_2.py
```
...и так далее для остальных заданий.

Если вы хотите запустить сразу все тесты, просто выполните команду `python -m pytest` из корневой папки проекта.

## 📝 Задания

### Задача 1: Утилита `echo`

*   **Файл для вашего кода:** `tasks/task_1.py`
*   **Задача:** Напишите скрипт `echo.py`, который выводит в консоль все аргументы командной строки, которые ему были переданы.
*   **Требования:**
    1. Скрипт не должен выводить свое имя (`sys.argv[0]`).
    2. Аргументы должны быть выведены в `sys.stdout` в одну строку, разделенные одним пробелом.
    3. В конце вывода должен быть символ новой строки (`\n`).
    4. Если скрипту не передано ни одного аргумента, он должен вывести пустую строку.
*   **Примеры использования:**
    ```bash
    # Выведет: Hello world from Python
    $ python tasks/task_1.py Hello world from Python

    # Выведет: one_argument
    $ python tasks/task_1.py one_argument

    # Ничего не выведет (только перенос строки)
    $ python tasks/task_1.py
    ```
*   **Команда для проверки:** `python -m pytest tests/test_task_1.py`

### Задача 2: Валидатор пароля

*   **Файл для вашего кода:** `tasks/task_2.py`
*   **Задача:** Напишите скрипт `password_validator.py`, который принимает два аргумента: пароль и его подтверждение. Он проверяет, совпадают ли они и соответствует ли пароль минимальной длине.
*   **Требования:**
    1. Скрипт должен принимать ровно два аргумента: `password` и `password_confirmation`.
    2. Если количество аргументов отлично от двух, вывести в `sys.stderr` сообщение `Ошибка: Укажите пароль и его подтверждение.` и завершить работу с кодом `1`.
    3. Если пароли не совпадают, вывести в `sys.stderr` сообщение `Ошибка: Пароли не совпадают.` и завершить работу с кодом `2`.
    4. Если длина пароля меньше 8 символов, вывести в `sys.stderr` сообщение `Ошибка: Пароль слишком короткий (минимум 8 символов).` и завершить работу с кодом `3`.
    5. Если все проверки пройдены успешно, вывести в `sys.stdout` сообщение `Пароль принят.` и завершить работу с кодом `0`.
*   **Команда для проверки:** `python -m pytest tests/test_task_2.py`

### Задача 3: Счетчик строк в файле

*   **Файл для вашего кода:** `tasks/task_3.py`
*   **Задача:** Напишите скрипт `line_counter.py`, который принимает в качестве аргумента путь к файлу и подсчитывает количество строк в нем.
*   **Требования:**
    1. Скрипт должен принимать ровно один аргумент — путь к файлу.
    2. Если аргумент не передан, вывести в `sys.stderr` сообщение `Ошибка: Укажите путь к файлу.` и завершить работу с кодом `1`.
    3. Если файл по указанному пути не найден, вывести в `sys.stderr` сообщение `Ошибка: Файл не найден.` и завершить работу с кодом `2`.
    4. Если файл успешно прочитан, вывести в `sys.stdout` единственное число — количество строк в файле. Завершить работу с кодом `0`.
*   **Команда для проверки:** `python -m pytest tests/test_task_3.py`

### Задача 4: Простой `cat`

*   **Файл для вашего кода:** `tasks/task_4.py`
*   **Задача:** Напишите скрипт `simple_cat.py`, который читает строки из `sys.stdin` и выводит их в `sys.stdout` с добавлением нумерации.
*   **Требования:**
    1. Скрипт не принимает аргументов командной строки.
    2. Скрипт должен читать данные из `sys.stdin` построчно до тех пор, пока поток не будет закрыт.
    3. Каждую прочитанную строку скрипт должен выводить в `sys.stdout`, добавив в начало номер строки, двоеточие и пробел. Нумерация начинается с `1`.
    4. Формат вывода: `N: <содержимое строки>`.
*   **Команда для проверки:** `python -m pytest tests/test_task_4.py`

### Задача 5 (Финальное): Утилита `grep` (комбинация всего)

*   **Файл для вашего кода:** `tasks/task_5.py`
*   **Задача:** Напишите скрипт `simple_grep.py`, который фильтрует строки из стандартного потока ввода (`sys.stdin`), оставляя только те, которые содержат заданную подстроку.
*   **Требования:**
    1. Скрипт должен принимать ровно один аргумент — подстроку для поиска (`pattern`).
    2. Если количество аргументов не равно одному, вывести в `sys.stderr` сообщение `Ошибка: Укажите паттерн для поиска.` и завершить работу с кодом `1`.
    3. Скрипт должен читать строки из `sys.stdin`.
    4. Если строка из `sys.stdin` содержит `pattern`, она должна быть выведена в `sys.stdout`.
    5. Если ни одна строка не содержит `pattern`, скрипт ничего не выводит в `stdout`, но все равно завершается успешно.
    6. По завершении чтения потока скрипт должен завершиться с кодом `0`.
*   **Команда для проверки:** `python -m pytest tests/test_task_5.py`
